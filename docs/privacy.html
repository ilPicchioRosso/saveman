Norme sulla privacy di saveman

saveman è un'app personale e open source per Nintendo Switch. Non esiste alcun server dello sviluppatore.

  • L'app accede al Google Drive dell'utente solo con il permesso drive.file: può vedere e gestire esclusivamente i file e le cartelle che crea lei stessa.
  • I salvataggi vengono caricati direttamente dalla console al Google Drive dell'utente. Lo sviluppatore non li riceve né li conserva.
  • Le credenziali (client secret e token di accesso) sono salvate solo sulla microSD dell'utente, nel file config.json.
  • Non vengono raccolti dati personali, statistiche o dati di utilizzo.
  • L'utente può revocare l'accesso in qualsiasi momento da myaccount.google.com/permissions.

Privacy policy (English)

saveman is a personal open-source app. It has no developer server. It uses only the drive.file scope, so it can access only files it creates in the user's own Google Drive. Saves go directly from the console to the user's Drive; credentials are stored only on the user's microSD card. No personal or usage data is collected. Access can be revoked at any time at myaccount.google.com/permissions.
